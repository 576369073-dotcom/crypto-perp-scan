# crypto-perp-scan

USDT 永续合约多周期共振扫描（Gate USDT 永续全市场，约 590 个合约）。

- 周期：1D / 4H / 1H / 15M（只用已收盘K线）
- 指标：MACD(12,26,9) + EMA(7/25/99)，参数不可改
- 筛选：1D、4H 顺周期 → 1H 逆周期且处于底部结构 → 15M 顺周期；EMA 要求 4H/1H/15M 不跌破 25 日线或回踩收回
- 推送：仅 S 级（双指标共振）/ A 级（MACD 5/5），24h 成交额 ≥ 2000 万 USDT，同一信号 12 小时只推一次，A→S 升级再推一次，每天最多 2 条，当日亏损达本金 20% 熔断
- 定时：GitHub Actions，每 15 分钟一轮（`.github/workflows/scan.yml`）

详细说明见 `DEPLOY.md`。
